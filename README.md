# 🌿 Smart Crop Disease Detection System

A real-time computer vision application built with **YOLOv8** and **Streamlit** to detect and identify crop pathology in field photographs.

🔗 **Live Demo:** [Click here to view the web app](https://smart-crop-disease-detection-sdpdtcq2d9apje5fw2o8no.streamlit.app/)

Key Features
Real-time Object Detection: Identifies crop leaf disease symptoms using custom-trained YOLOv8 weights.

Interactive Threshold Tuning: Configurable confidence slider to minimize false positives in noisy agricultural environments.

Pathology Summary: Automated detection logs providing instant visual bounding boxes and exact percentage confidence scores.

🛠️ Tech Stack
Computer Vision: YOLOv8 (Ultralytics), OpenCV, PyTorch

Frontend / Deployment: Streamlit, Streamlit Cloud

Language & Version Control: Python 3.11, Git, GitHub CLI
